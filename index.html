Image from
Choose an imageor drop one here. PNG, JPEG, GIF, WebP or SVG.

The image is shrunk and compressed here in your browser, then built into the signature, so it travels with it. Apple Mail and Outlook keep it when you paste. Gmail doesn’t: it removes pasted images. For Gmail, paste the signature, then add the image with the image button in Gmail’s signature editor, using the “Download resized image” copy.

Use this if the image is already online, for example on your website. It works in every mail app, Gmail included, though some recipients only see it after clicking “show images”.

    Where to paste it

    Gmail (web)

    1. Settings (gear) → See all settings → General.
    2. Signature → Create new, name it, click in the box and paste.
    3. Choose it under “Signature defaults”.
    4. Scroll to the bottom and Save Changes.

    Outlook

    1. New Outlook and Outlook on the web: Settings → Account → Signatures.
    2. Classic Outlook for Windows: File → Options → Mail → Signatures.
    3. Outlook for Mac: Outlook → Settings → Signatures.
    4. Create a new signature, paste, set it as the default and save.

    Apple Mail (Mac)

    1. Mail → Settings → Signatures, pick the account, click +.
    2. Untick Always match my default message font first, or the styling is removed.
    3. Select the placeholder text and paste.

    iPhone and iPad

    1. Settings → Apps → Mail → Signature.
    2. iOS keeps very little formatting. Use Copy plain text.

    Thunderbird

    1. Account Settings → your account.
    2. Tick Attach the signature from a file and choose the downloaded .html file.
    3. Or tick Use HTML and paste the HTML code.

    If a paste comes out unstyled, open the downloaded .html file in a browser, press Ctrl+A (Cmd+A on a Mac), copy, and paste that instead.
